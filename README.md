An AI-powered system to detect electricity theft using Machine Learning.

## 🔍 Problem Statement
Electricity theft causes $96 billion in losses globally every year. 
This project uses ML to detect theft patterns from smart meter data.

## 📊 Dataset
- Source: SGCC (State Grid Corporation of China)
- Customers: 42,372
- Days of readings: 1,034
- Theft rate: 8.53%

## 🔑 Key Findings (EDA)
- Theft customers consume 294% MORE than normal customers
- 25.64% missing values in dataset
- Severe class imbalance: 91.47% normal vs 8.53% theft
